# 📌 Sobre o Projeto

O **Sistema de Chamados** é uma aplicação frontend desenvolvida para gerenciamento de chamados técnicos, clientes e equipes de atendimento.

O sistema possui autenticação, controle de permissões por função e organização modular baseada em componentes, contextos e layouts reutilizáveis.

---

# ✨ Funcionalidades

✔️ Sistema de login e autenticação  
✔️ Controle de permissões por perfil  
✔️ Gerenciamento de chamados  
✔️ Cadastro de clientes e técnicos  
✔️ Chat em tempo real  
✔️ Modais dinâmicos  
✔️ Interface responsiva  
✔️ Context API para gerenciamento de estado

# ⚙️ Como Executar

## 1️⃣ Clone o repositório

```bash
git clone https://github.com/aamoorim/sistema-de-chamados.git
```

---

## 2️⃣ Instale as dependências

```bash
npm install
```

---

## 3️⃣ Execute o projeto

```bash
npm run dev
```

A aplicação ficará disponível em:

```bash
http://localhost:5173
```
